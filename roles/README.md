# roles/

The six protocol roles — `analyst`, `planner`, `implementer`, `reviewer`, `validator`, `arbiter` — one file each, each a compact contract: identity, objectives, guidelines, constraints, output.

Roles are protocol semantics (WHO acts), never session requirements: a role file defines a bounded function with its own success criteria and says nothing about session arrangement — that is an execution-mode decision made per risk class. See [`protocol/spec.md`](../protocol/spec.md), sections 3 and 4.
